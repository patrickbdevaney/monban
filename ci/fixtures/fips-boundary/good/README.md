# Fixture README

**FIPS 140-3.** AEGIS is not a validated cryptographic module and makes no FIPS validation claim. The cmvp
profile uses the AWS-LC FIPS 140-3 validated module (CMVP certificate #5314, static; #5298 only applies if the
build is made dynamic) on its validated operating environments.

SecP384r1MLKEM1024 (0x11ED) is never described as FIPS-approved as a whole; its components are.
