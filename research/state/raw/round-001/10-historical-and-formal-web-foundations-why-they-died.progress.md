## S1 Ur/Web POPL'15 (NOT PLDI; DOI 10.1145/2676726.2677004) https://css.csail.mit.edu/6.858/2015/readings/urweb.pdf
- compiler SML ~55,000 LOC; server runtime ~5,000 LOC C; client ~1,500 LOC JS. Code = ASTs (no string concat injection); only persistent state = typed SQL; whole-program analysis for client/server sidedness -> confusing error messages = top pain point; metaprogramming (dependent-type-ish) barely used by prod apps.
- TechEmpower Round 9 fortunes, 40 hw threads: best latency 2.1ms, 4th-best throughput ~110k req/s among ~60 frameworks/70 configs; does poorly on many-writes test (txn analysis + restart cost).
- Adoption: 12 external patch contributors; BazQux Reader 2500 paying users, 10 req/s avg, peaks>150; Bitparking exchange "spotless record" re CSRF etc. over 2 yr.
