## Checkpoint 5 (00:12) — contrarian + authz-model docs
- CONTRARIAN (Envoy extensions_metadata.yaml, main @2026-10-25): every DB wire-protocol filter is security_posture=requires_trusted_downstream_and_upstream: redis_proxy (stable), mongo_proxy (stable), thrift_proxy (stable), zookeeper_proxy (alpha), contrib postgres_proxy (stable), mysql_proxy (alpha), kafka_broker/kafka_mesh (wip). Only rbac/ext_authz/tcp_proxy/sni_dfp/postgres_inspector are robust_to_untrusted_downstream. => A mature proxy does not harden native DB protocol parsers against untrusted clients. Implication: the server should GENERATE backend wire requests from a typed IR (it is the client), never accept/parse native DB protocol from untrusted downstream.
