## CRA (primary text via cyberresilienceact.eu reproduction of OJ; EUR-Lex blocks bots with 202/WAF — secondary reproduction, flagged)
- Art3(13) manufacturer incl. "whether for payment, monetisation or free of charge"; Art3(14) steward = LEGAL PERSON, other than manufacturer, systematically supporting FOSS "intended for commercial activities"; Art3(22) making available = "in the course of a commercial activity, whether in return for payment or free of charge".
- Art24: steward = documented verifiable cybersecurity policy, cooperate w/ MSA, Art14(1) only if involved in development; 14(3),(8) only for incidents hitting steward's infra.
- Art64(10)(b): NO administrative fines for ANY infringement by stewards. Art64(2): 15M/2.5% for Annex I + Art13/14 breaches (manufacturers).
- Art71: Art14 applies 2026-09-11; Chapter IV (notified bodies) 2026-06-11; rest 2027-12-11.
- Art13(5) due diligence on integrated FOSS components even non-commercial -> downstream manufacturers will demand SBOM/vuln policy from us.
- Annex III class I includes OS, PKI software, VPN, SIEM, NMS, IdM/PAM; class II firewalls/IDPS, hypervisors+container runtimes. Web server/reverse proxy NOT listed; WAF-function could be argued 'firewall' -> risk (Annex III class II) . Art32(5): FOSS important products may use default (module A self-assessment) route if tech docs public.
- Annex I Part I(2)(a)-(m), Part II(1)-(8): SBOM machine-readable top-level deps, CVD policy, secure update distribution, security logging w/ opt-out (I(2)(l)), integrity report corruptions (I(2)(f)).
- Commission guidance C(2026)5252 approved 2026-07-27 as draft: web apps accessed via browser not products; software on user's device is; sharing code on public repo generally not placing on market.
