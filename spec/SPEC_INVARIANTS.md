## B. State and effects

**INV-NOMUT-C (F4), NC1–NC8.** NC1 every termination of r before CP(r) (return, error, panic, timeout, h1 close, h2 RST_STREAM, h3 STOP_SENDING, abort, trap, crash) ⇒ Outcome(r) = Failed ∧ ΔDurableUserRows(r) = ∅ (mod sequence values, advisory locks, stats). NC2 from CP(r) on, r is not cancellable and its outcome is latched; a timer after CP yields 202 + idempotency retrieval. NC3 a resource in D(r) that a cancelled request touched, or that was left mid-protocol, is quarantined (never handed to another request) and either recovered or discarded. Recovery = drain every outstanding reply to ReadyForQuery WITHOUT a CancelRequest (the in-flight statement is bounded by statement_timeout = op budget ms), ROLLBACK if the server-reported txn status is not I, DISCARD ALL, and invalidate driver-side statement/type caches (session generation bump), all within T_recover = op budget; checkin iff ReadyForQuery ∧ server-reported txn status I ∧ no outstanding replies ∧ all server objects closed. Any error, timeout, COPY in progress, LISTEN or unknown protocol state ⇒ discard; discard sends a CancelRequest (or relies on client_connection_check_interval) so the orphan backend stops. A CancelRequest is never sent on a connection that will be checked back in. Quarantine time and discards are charged to the cancelling principal (NC4). (Adopted from spike q3-008: discard-on-cancel costs a backend fork + auth per cancel, 30–53 cancels/s on a 1-vCPU-class core.) NC4 budgets debited before work; cancels are charged. NC5 cancelled authz stage ⇒ Deny. NC6 external effects only through the outbox. NC7 no response body bytes before CP. NC8 drain completes within T_drain. Host-enforced (survive malicious modules): NC1/3/4/5/8. → R1 cancel sweep, R2 DST, TLA+/P with cancel as nondeterministic action, Lean/Kani NC4/NC5. Reached: R1. `ac.l5-inv-nomut-c` B.

## C. Resources (F5)

**TBI-1** decoded field block ≤16,384 RFC bytes ∧ ≤128 fields (incl. cookie crumbs). **TBI-2** decode work ≤ K₁·|wire| + K₂·|decoded|. **TBI-3** HPACK table ≤4,096; QPACK = 0. **TBI-4** live handlers ≤100 and queued ≤400 per connection; permit held for the task's lifetime. **TBI-5** RST bucket burst 100, refill 33/s; server-originated resets ≤256; total streams ≤10,000 per connection. **TBI-6** buffered bytes ≤ advertised connection window. **TBI-7** per-connection memory ≤ M_conn (16 MiB target); N·M_conn ≤ global. TBI-6 does not imply TBI-7 (a peer advertising a huge window and then not reading makes every stream's send buffer fill: 40.6 MiB/conn measured), so the bound is min(peer window, local send ledger): a chunk is handed to the stack only while bytes-handed − bytes-written + chunk ≤ 12 MiB, plus an explicit SO_SNDBUF cap (kernel buffers are outside RSS). hyper holds one 16 KiB frame per open stream even at window 0, so TBI-6 carries one frame of slack per stream (spike q2-009). **TBI-8** no stream stalls >10 s without progress; idle connection closed at 30 s. **TBI-9** no counter overflow. → Kani TBI-5/6/9; Verus TBI-1/4/7 (ghost multiset permits_out + available = S); Lean composition; proptest TBI-2; DST TBI-8. ## E. Data plane (F7, F9)

**Lowering soundness.** Policy semantics are three-valued: ⟦p⟧(x) := eval3(x, p) = some true, where an absent/NULL field makes every atom UNKNOWN and connectives are Kleene (`eval3`, `refQ3`). ∀ pred p (NOT included), tenant t, row x: Backend.Exact(engine) ⇒ sql3(render(lowerQ(t,p)), x) = eval3(x, tenant = t ∧ p) (`lower_exact3`, `lowerQ_exact3`); hence rows(render(lowerQ(t,p)), db) = {x ∈ db | x.tenant = t ∧ ⟦p⟧(x)} (`rows_exact3`: no leak, no miss). Under Refines only, NOT-free predicates satisfy rows ⊆ {x | x.tenant = t ∧ ⟦p⟧(x)} (`lower_sound_pos3`, `lowerQ_sound`); NOT requires Exact (`refines_insufficient_for_not3`), so F4 admits `Not` only on Fidelity::Exact adapters, over nullable and non-nullable fields alike. Relation to the two-valued reference `eval` (absent ⇒ atom false): 3VL is never more permissive (`eval3_sound`, `refQ3_imp_refQ`), coincides on NOT-free predicates (`eval3_pos_iff`, `refQ3_pos_eq`) and on rows where every read field is present (`eval3_total`); they differ exactly on NOT over an absent field, where 2VL permits and 3VL denies (`not_absent_gap`): a policy `NOT (f = v)` does not match rows whose f is NULL. `In []` is FALSE on a present column and UNKNOWN on NULL (`sql3_inList_nil`); a constant-FALSE rendering is not exact under NOT (`inList_nil_not_const_false`). Coarser engine equality (NOCASE, affinity, nondeterministic ICU) breaks soundness (`refines_necessary`), so tenant and key columns must use a binary/deterministic collation (schema gate). **Checked:** lower_sound_pos, lowerQ_sound, refines_necessary, lower_sound_full, lowerQ_sound_full, not_absent_permits, lower_exact3, lowerQ_exact3, rows_exact3, eval3_sound, refQ3_imp_refQ, eval3_pos_iff, refQ3_pos_eq, eval3_total, not_absent_gap, sql3_inList_nil, inList_nil_not_const_false, lower_sound_pos3, refines_insufficient_for_not3; vacuity witnesses in Vacuity.lean and ThreeValued.lean (exact3_nonvacuous_null/present). Executed contract (oracles/lowering-read): leak = 0 ∧ widen = 0 ∧ miss = 0 against `refQ3` (permit3 = model; GAP vs the 2VL `refQ` is reported as information only), ≥100k cases per ENGINE_PIN. `q4-004.three-valued-reference` A. Adopted 2026-10-25 from spike q4-004 (replaces the 2VL clause and the reject-NOT-over-nullable rule).

**INV-WRITE-SUBSET W1–W7 (text from R-DB-8).** W1 every changed key's pre-image has tenant t and (for Update/Delete) satisfies Pred. W2 every post-image has tenant t. W3 upsert/merge arbiter is exactly (t, key): it is the table's ONLY unique index, full-length (no prefix key parts), over binary, deterministic, NO-PAD collations (NOCASE/ICU: guarded upsert silently no-ops, 51/1200 cases; MariaDB utf8mb4_bin pads trailing spaces; MariaDB arbitrates ON DUPLICATE KEY on any unique index and returns the foreign row via RETURNING; Cockroach UPSERT always uses the primary key: spike q4-005). ## H. Golden extension contract (survival under malicious modules)
Survive: I1, I2, I5, I6-host, I7. Assume golden: I3 external effects, I4 microarchitectural. Host decoders of module output are in the verified TCB. `vfg-invariant-survival-table` B.

**INV-P2 (addendum 2026-10-31, Phase 5, P5-spec-001; PLAN D1, D2, D5–D9; spike q4-006; F14, F8 `p2`).** P2 code (agent-generated Wasm) runs only as an F14 core module, one fresh instance per request, never a reused instance. P2-1 path: a multi-principal module runs on the configured default path (F8 `p2.isolation`, default `forkwasm` per q4-006: fork child of an exec-spawned single-threaded zygote that holds Engine + locally precompiled Module + InstancePre and no compiler state; per-request fuel + ITIMER_REAL wall bound) or `cordon`; a single-tenant module runs in a per-principal cordon (fresh instance per request, 64-slot pool, fuel + 100 ms epoch). Switching the path is a config change plus reload, with no rebuild, and the same route answers correctly under both. P2-2 principals never share a cordon: the cordon key is the principal, no configuration can express a shared cordon (F8 `additionalProperties: false`), and aegis-iso refuses a second principal on a cordon at runtime. P2-3 exec respawn: every zygote, cordon and compile process, first or replacement, is a fresh execve of aegis-p2 (new ASLR layout), never a fork of a template (R-ISO-5). Residual (D9): fork children share the zygote's layout; layout probing by crashing children is bounded by P2-4, and the zygote never serves a request. P2-4 crash budget, per principal: `crashes` crash-attributable faults (trap, abnormal child exit, cordon death, F14 decode failure caused by that principal's request) within `window_s` ⇒ that principal's P2 requests get 429 for `penalty_s`; defaults 3, 60 s, 600 s; healthy failures and other principals' faults never count. P2-5 every zygote, cordon and fork child runs with PR_SET_DUMPABLE = 0 and PR_SET_NO_NEW_PRIVS = 1. P2-6 sandbox (D2, D5), installed once per process before it serves, Landlock first: Landlock ABI ≥ 4 is required, else every P2 route is refused at boot (exit 78, fail closed); fs read-only on the module and data paths only, net with no rule allowed; no cordon or zygote relies on any namespace. Then one seccomp filter: an argument-free allowlist of hot syscalls; CLONE_NEW* flags ⇒ kill; clone3 ⇒ ENOSYS; KILL_PROCESS for unshare, setns, socket, socketpair, setsockopt(TCP_ULP), bpf, perf_event_open, io_uring_setup/enter/register, ptrace, process_vm_readv/writev, userfaultfd, keyctl/add_key/request_key, the mount family, execve and execveat. The zygote keeps accept4 on its inherited listening fd; each fork child adds a filter killing clone, fork, vfork and execve; a cordon has no fork. A negative probe passes only on the filter's own signature (SIGSYS from KILL_PROCESS, or ENOSYS for clone3), never on EPERM or another kernel or AppArmor denial. P2-7 F14 boundary: the supervisor's decoders of worker frames are in the verified TCB; a decode failure kills the worker and charges P2-4, never the supervisor; the supervisor re-serializes every byte a module emits and forwards nothing before an Allow completion (I5); every data_run is decoded, its tenant overwritten, authorized against the route CapSet (INV-NONEMPTY) and audited before it executes (I1, I6-host); a module decision is one input to the tri-state combiner and error, timeout, trap or worker death ⇒ Deny (I7, INV-FAILCLOSED); fuel, the wall bound, the memory limiter and the per-request host-call and byte quotas hold at the worker and are re-checked at the supervisor (I2). P2-8 Wasmtime (R-ISO-2, D11): the pinned version and the effective config frozen in `supply-chain/wasmtime-config.toml`; 4 GiB reservation and 32 MiB guard never shrunk; MPK only as a density option with both asserted unchanged; a `.cwasm` is deserialized only if its sha256 equals the digest of this boot's sandboxed compile, never bytes from config or a tenant. **Acceptance (q4-006, oracles/isolation-fi, at a 1% fault rate, per path):** ≤ 0.05 crash-attributable healthy failures per fault (0 measured in q4-006) and 0 wrong answers per fault on the six guest classes (panic, abort, segv, loop, oom, poison), plus hostabort and hostpoison for fork+Wasm (for a per-principal cordon these two are reported as that principal's damage, not gated); poison 0; recovery (service gap) p99 ≤ 5 ms; throughput ≥ 0.5× at 1% loop; the hostile-module corpus holds I1, I2, I5, I6-host and I7 on both paths. → R1 executed gates p2-fault-forkwasm, p2-fault-cordon, p2-syscall-negative, p2-hostile-worker, p2-hostile-host, p2-e2e, wasmtime-config, p2-fault-vps (gates/phase-5.toml).
