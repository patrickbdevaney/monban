## E. Data plane (F7, F9)

**Lowering soundness.** ∀ pred p, tenant t, row x: Backend.Exact(engine) ∧ sql3(render(lowerQ(t,p)), x) = some b ⇒ refQ(t,p,x) = b (`lower_sound_full`); hence rows(render(lowerQ(t,p)), db) ⊆ {x ∈ db | x.tenant = t ∧ ⟦p⟧(x)} (no leak), under Refines as well (`lowerQ_sound`). Equality holds only where SQL never yields UNKNOWN; NOT over an absent field makes the reference permit a row that SQL drops (`not_absent_permits`: a miss, never a leak). F4 therefore rejects NOT over nullable fields until a three-valued reference is proved (q4-004). Coarser engine equality (NOCASE, affinity, nondeterministic ICU) breaks soundness (`refines_necessary`), so tenant and key columns must use a binary/deterministic collation (schema gate). **Checked:** lower_sound_pos, lowerQ_sound, refines_necessary, lower_sound_full, lowerQ_sound_full, not_absent_permits; vacuity witnesses in Vacuity.lean. Executed contract (oracles/lowering-read): leak = 0 ∧ widen = 0 ∧ miss = 0 against Lean semantics, the UNKNOWN gap reported separately, ≥100k cases per ENGINE_PIN. Corrected 2026-10-25: the earlier text claimed equality on exact engines, which the theorems do not state. `r4e01.lower-sound-full-proved` A.

**INV-WRITE-SUBSET W1–W7 (text from R-DB-8).** W1 every changed key's pre-image has tenant t and (for Update/Delete) satisfies Pred. W2 every post-image has tenant t. W3 upsert/merge arbiter is (t, key) under a binary/deterministic collation (on NOCASE or nondeterministic ICU tenant columns the guarded upsert silently no-ops: 51/1200 cases, oracles/lowering-write). W4 RETURNING ⊆ permitted. W5 closure over triggers, data-modifying CTEs and FK actions. W6 uniform failure for foreign keys (no existence oracle). W7 Redis reply subset. Mandated forms (not invariants): composite arbiters, FORCE RLS + explicit WITH CHECK, no REPLACE family, upsert WHERE without user expressions. → R2 executed W1/W2/W4; R4 Lean W1–W6 over an abstract engine. `wpo-inv-write-subset`.
